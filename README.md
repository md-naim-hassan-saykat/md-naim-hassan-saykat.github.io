# md-naim-hassan-saykat.github.io

Source of the academic portfolio of **Md Naim Hassan Saykat**: <https://md-naim-hassan-saykat.github.io>

AI researcher working on medical image analysis, computer vision, explainable AI and AI governance; Master's student in Artificial Intelligence at Université Paris-Saclay and independent researcher, Bangladesh.

- **Projects:** generalizable skin-lesion classification, the Bangladesh AI Policy & Innovation Lab (BAPIL), patent retrieval, generative models and NLP
- **Publications:** journal manuscripts, the BAPIL Technical Blueprint, Blueprint Summary, White Paper and Executive Summary (Zenodo DOIs)
- **ORCID:** [0009-0007-5270-3970](https://orcid.org/0009-0007-5270-3970)

## Build

The site uses the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and is built and deployed by GitHub Actions (`.github/workflows/deploy.yml`) on every push to `main`. To preview locally: `bundle install` then `bundle exec jekyll serve`.

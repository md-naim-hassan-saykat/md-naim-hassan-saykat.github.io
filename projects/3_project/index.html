This project implements a multi-task learning framework for emotion recognition across modalities. The system simultaneously processes speech signals and text data to predict emotional states with shared learned representations, improving generalization and robustness across input domains.

Architecture Overview

Model Components
  • Speech Module: Mel-spectrogram feature extraction + CNN/RNN encoder
  • Text Module: Token embeddings + Transformer-based encoder
  • Shared Representation: Joint embedding space for multi-task learning
  • Task Heads: Independent classifiers for speech emotion & text emotion

Key Features

  • Multi-modal fusion with attention mechanisms
  • Cross-task auxiliary learning for improved generalization
  • Balanced loss weighting across emotion classes
  • End-to-end training with gradient balancing

Results

The multi-task framework achieved competitive accuracy across both speech and text modalities, with improved robustness compared to single-task baselines. Shared representations enabled better handling of noisy or incomplete inputs.
